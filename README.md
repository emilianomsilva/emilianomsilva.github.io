Official multilingual academic website and research portfolio of **Emiliano M. Silva** (Chemist, Civil Engineer, M.Sc. in Geosciences, Ph.D. Candidate in Mining Engineering).

---

## 📌 Features & Architecture

- **Single-Page Dashboard Layout**: Single-page architecture with a collapsible sidebar, fast smooth-scrolling section anchors, and `SECTION ## ↑` back-to-top buttons.
- **Multilingual Support**: Monolingual-per-locale structure in **English (`/en/`)**, **Portuguese (`/pt/`)**, and **Spanish (`/es/`)**.
- **Publication-Backed Research**: Focused on 3 publication-backed research axes (Mercury-Free Gold Processing, Mine Waste Valorization, and Field Metallurgical Diagnostics).
- **Direct Google Forms Contact Integration**: Asynchronous contact submission directly linked to Google Forms & Google Sheets without page reloads.
- **Responsive Mobile Aesthetics**: Adaptive layout rules for desktops, tablets, and smartphones.
- **Permanent QR Code Support**: High-resolution vector SVG and PNG QR codes linking to `https://emilianomsilva.github.io/`.

## 🚀 Local Development

To run the site locally using Hugo Extended:

```bash
hugo server -D
```

Open your browser at `http://localhost:1313/`.
