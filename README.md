Multilingual personal website and portfolio of **Emiliano M. Silva**, combining an academic research profile with a real-estate portfolio.

## Contents

- Academic profile with biography, education, experience, competencies, research, publications, portfolio and contact sections.
- Real-estate portfolio with property pages, image galleries, maps and tenant contact forms.
- English, Portuguese and Spanish versions under `/en/`, `/pt/` and `/es/`.
- Responsive layouts with desktop sidebars and mobile topbars.
- Contact forms connected to Google Forms.

## Stack

- Hugo Extended and Go templates
- SCSS compiled by Hugo Pipes
- YAML data files and TOML translations
- GitHub Actions and GitHub Pages

## Development

Run the local server:

```bash
hugo server -D
```

Build the production site:

```bash
hugo --minify
```

The local server is available at `http://localhost:1313/`.
